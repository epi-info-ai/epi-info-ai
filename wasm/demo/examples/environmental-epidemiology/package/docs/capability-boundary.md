# Environmental Epidemiology capability boundary

This demonstration package contains inert provider-catalog, validation, and
documentation assets. It installs no JavaScript, WebAssembly, Worker, model, or
credential and grants no network or execution authority.

The application supplies the typed environmental review surface and the
`epi-gis` Worker/kernel. A future reviewed provider adapter may turn a learner's
bounded request into an effective retrieval plan, but the user must inspect and
authorize that plan before any network action. Successful retrieval would not,
by itself, establish that a dataset is scientifically suitable for exposure
assessment.

The separately importable Heat and Health teaching project contains only
synthetic observations, a saved descriptive program, a learner-operated
runbook, and a project map layer. It is evidence for workflow integration, not
an approved exposure model or health-effect method.
