Analysis profile

GDAL masks the WGS 84 population surface to each zone using nearest-neighbor resampling, retains NoData, and calculates Worker-side band statistics. Epi Info derives coverage and cases per 100,000 population units.

Denominator boundary: the fixture is WorldPop-derived but carries no authoritative unit metadata. Values are treated as population units solely for this architecture test. Production rates require the investigator to confirm raster year, population concept, units, CRS, resolution, and study-area suitability.
