# GIS-K07 Dot Density teaching fixture

This synthetic project demonstrates bounded Dot Density mapping from a local
boundary GeoJSON and form data. Use `GEOID` with `county_fips`, `cases` as the
value field, and `10` as the value per dot. The third row is intentionally
orphaned so the Maps layer reports a join diagnostic.

This fixture is for teaching and contract evaluation; it is not surveillance
data and does not establish legacy desktop parity by itself.
