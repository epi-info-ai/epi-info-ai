CDC's current Epi Info page identifies this PDF as the historical reference document and describes Epi Info as a public-domain suite. The manual covers Introduction, Form Designer, Check Code, Enter, Web Survey, Companion for Android, Data Packager, Visual Dashboard, Classic Analysis, Maps, Nutritional Anthropometry, StatCalc, Command Reference, Functions and Operators, Glossary, and Appendix.

Use this manual as a functional and terminology reference, not as the new application's architecture. Features should be entered into a compatibility matrix and classified as:

1. required for initial outbreak workflows;
2. supported through a browser-native equivalent;
3. import-only or compatibility behavior;
4. intentionally unsupported because it is obsolete, unsafe, or platform-specific.

The manual is historical and may not describe the repository's latest code exactly. Verify calculation behavior against source, tests, and independently trusted statistical references.
